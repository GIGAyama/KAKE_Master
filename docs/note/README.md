# note 入稿メモ（九九カード）

連載「教室で使えるかもしれないもの作り」に載せる紹介記事一式です。

```
docs/note/
├── kuku-card-note-article.md   記事本文。note にそのまま貼れる形
├── images/                     実際に操作して撮った画面 25 点
└── README.md                   このファイル
```

## 貼るまえに直してほしいところ

1. **連載番号**。本文1行目のタイトルが `#◯` のままです。推測で埋めていないので、正しい番号に置きかえてください。
2. **公開 URL**。本文の「はじめに」に `https://kake-master.giga-school.com/` と書いています。`CNAME` がこのサブドメインを指しており、`manifest.webmanifest` の `scope` も `"./"`（＝サブドメイン直下）なので、この場所で配信される前提です。撮影環境から外部へのアクセスが制限されていて、実際に開いて確かめることができませんでした。公開済みかどうかだけ、目で確かめてください。
3. **教室での様子**。この記事は作者の実践記録ではないので、「使ってみたら子どもたちが〜」は一行も書いていません。実際に授業で使った話は、書き手が自分で足すところです。

## note に貼る手順

1. note の新規記事を開き、本文1行目の `# 教室で…` をタイトル欄に貼る。本文からは消す
2. 残りをそのまま本文欄に貼る。見出しは `##` と `###` だけなので、note の目次がそのまま作られる
3. 画像は自動では上がらないので、`images/` の中身を本文の該当位置に手でアップロードする。ファイル名の番号が本文に出てくる順番です
4. 画像の下に置いてある1行のキャプションは、note のキャプション欄に移す。本文からは消す
5. ハッシュタグは `#GIGAスクール` `#小学校` `#算数` `#かけ算九九` `#教育ICT` あたり

## 撮り直すときの手順

このアプリはビルドが要りません。リポジトリの中身をそのまま配れば本番と同じ状態になります。

```bash
npm i --no-save playwright

# 別のターミナル、または背景で。第3引数のサブパスを省かないこと
node <skill>/scripts/serve.mjs . 4180 /KAKE_Master/

# 撮影用のシナリオを置いて走らせる
node <skill>/scripts/capture.mjs .tmp-shots/shots.mjs \
  --base http://127.0.0.1:4180/KAKE_Master/ --out .tmp-shots/out
```

`shots.mjs` は今回使ったものを残していません（`.tmp-shots/` は納品前に消しています）。
撮り直すときに押さえておくとよい点は次のとおりです。

- カードは `<div>` なので、文字でボタンを探す `click()` では拾えません。`p.eval` で `.kcard.current` に click を投げます
- 紙ふぶきは3秒で消えます。結果画面をきれいに撮るなら、終わってから4秒ほど置いてください。紙ふぶき自体を撮るなら2秒あたりです
- 「マスター」を出すには、同じ段を3周して全部「できた!」にする必要があります
- 「まちがえたカード」や「にがてカード」を撮るには、わざと数問まちがえる必要があります。1問ごとに 900ms ほど置かないと、押している途中で画面が進んで正答率がおかしくなります
- 段の選び直しは、先に足してから外します。1つも選ばれていない状態にしようとすると注意の帯が出ます
- 縦に長い画面は、いま出ている画面の高さを測ってからビューポートを伸ばすと、下に余白を作らずに1枚で撮れます

字の形について、ひとつ補足です。撮影した環境は外部への通信が制限されていて、Google Fonts に届きませんでした。
そのままだと本番と字の形が変わってしまうため、Google が配っているのと同じフォントのファイルを手もとに置いて、
撮影のあいだだけそこから読ませています。アプリ側には手を入れていません。
外に出られる環境で撮る場合は、この用意はいりません。

撮影の前後で `git status` と `git diff` を確かめてあります。撮影のための一時的な変更はリポジトリに残っていません。

## 文体について踏襲したこと

- 太字、斜体、表、`→` のような記号は本文で使っていません。note のエディタに素直に貼れることを優先しています
- 箇条書きは手順のところだけです。それ以外は文章で書いています
- 専門用語は日常の言葉に置きかえています。デプロイ、ローカルストレージ、Service Worker といった言葉は本文に出てきません
- 絵文字は見出しだけです
- 見出しは基本の6本に、目玉のところで2本足しています。🎴 と 🗺️ の2本で、📱 と ✨ のあいだに入れています
- 効果は言い切らず、作者の見立てとして書いています
- 本文はおよそ7,400字です

## 撮影中に見つかった不具合

ありません。全モードを実際に最後まで通して操作しましたが、途中で止まる画面も、押しても反応しないボタンも、
アプリ側のエラーも出ませんでした。この記事は、そのまま公開して問題ありません。

撮影中に出た通信のエラーは、撮影環境が外部のフォントに届かなかったぶんだけです。アプリの不具合ではありません。
